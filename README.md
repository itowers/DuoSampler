# DuoSampler

Sampler e beat maker para o iPhone Duo (PWA, Web Audio). Protótipo.

- Pads 4×4 em três modos: DRUM, KEYS e CHORD
- Looper de 4 faixas com overdub em camadas, sequencer de 16 passos
- Sampler com microfone ou arquivo: cortar, fatiar, reverso, normalizar
- 4 kits de bateria e 12 sons de sintetizador

Instalar: abra o endereço do GitHub Pages no Safari → Compartilhar → Adicionar à Tela de Início.
